Instalação em 1 comando

Pré-requisitos: macOS, Claude Code CLI, Python 3.10+ e Setup 7 do ZX Control concluído.

Passo 1 · Clone
# clona o repo público
git clone https://github.com/zxmarketingdigital/zx-control-setup8-skills-agencia
cd zx-control-setup8-skills-agencia
Passo 2 · Abrir Claude Code
# abre Claude Code na pasta — ele vai te guiar pela instalação
claude
Passo 3 · Comando mágico
# dentro do Claude Code, digite:
INICIAR SETUP SEMANA 8

A partir daí o Claude executa tudo pra você — 5 etapas guiadas, ~15 minutos. Você não precisa digitar nenhum comando no terminal.
